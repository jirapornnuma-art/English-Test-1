คู่มือครูแบบง่ายมาก (ใช้กับ Google Sites และ Google Sheets)

A) วิธีนำขึ้น Google Sites

  1. ดาวน์โหลดไฟล์ ONET_P6_Colorful_GoogleSites.html
  2. คลิกขวาไฟล์ → เปิดด้วย Notepad
  3. กด Ctrl + A แล้ว Ctrl + C
  4. เข้า Google Sites แล้วสร้างเว็บไซต์ใหม่
  5. กด แทรก → ฝัง → ฝังโค้ด
  6. กด Ctrl + V วางโค้ดทั้งหมด
  7. กด ถัดไป → แทรก
  8. กด เผยแพร่ แล้วส่งลิงก์ให้นักเรียน

B) วิธีเชื่อม Google Sheets เพื่อเก็บคะแนนและจัดอันดับ

  1. สร้าง Google Sheets ใหม่ เช่น ONET P6 Leaderboard
  2. เปิดเมนู ส่วนขยาย → Apps Script
  3. ลบโค้ดเดิม แล้ววางโค้ดจากไฟล์ Leaderboard_GoogleSheet.gs
  4. กดบันทึก และกดรันฟังก์ชัน setup 1 ครั้ง
  5. เลือก Deploy → New deployment → Web app
  6. ตั้งค่า Execute as: Me และ Who has access: Anyone
  7. กด Deploy แล้วคัดลอกลิงก์ที่ลงท้ายด้วย /exec
  8. กลับมาแก้ไฟล์ HTML แล้วหา const LEADERBOARD_URL = '';
  9. วางลิงก์แทนช่องว่าง แล้วบันทึกไฟล์ HTML ใหม่
  10. คัดลอกโค้ด HTML ที่แก้แล้ว ไปฝังใน Google Sites อีกรอบ
บรรทัดที่ต้องแก้ในไฟล์ HTML
const LEADERBOARD_URL = '';
